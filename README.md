# DCInside Image Downloader (Personal Fork)

> [안내]
> 이 저장소의 기능 개선/버그 수정은 바이브 코딩 방식으로 빠르게 반영된 내용이 포함되어 있습니다.
> 실제 사용 전 직접 코드 검토와 충분한 테스트를 권장합니다.
> 사이트 구조/정책 변경에 따라 일부 기능이 언제든 동작하지 않을 수 있습니다.

디시인사이드 게시글의 본문 이미지를 내려받기 위한 크롬 확장프로그램 개인 포크 버전입니다.

원본 확장의 기본 기능은 유지하면서, 최근 페이지 구조/응답 변화로 발생하던 다운로드 문제를 수정하고 시리즈 다운로드 기능을 보강했습니다.

## 1. 원래 구현되어 있던 주요 기능

- 게시글 페이지에서 본문 이미지 다운로드 지원
- 시리즈(`[시리즈]`) 링크 옆 개별 `다운로드` 버튼 제공
- 시리즈 글을 백그라운드 탭으로 열어 순차 처리
- 첨부파일 영역 위치 이동 옵션 (`ElementMove`)
- 시리즈 처리 시 첨부파일 다운로드 경로 제어 옵션 (`IgnoreAttachment`)
- 파일명(폴더명) 패턴 옵션
- 파일 확장자 추론 후 저장 (`content-type`, `content-disposition` 기반)

## 2. 기존 코드 기준으로 확인된 버그 및 수정 사항

아래는 포크 작업 시점에 기존 코드에서 발생하던 것으로 확인된 문제들입니다.

- 일부 게시글 URL 타입에서 content script 미주입
- `mgallery`/`gallery` 게시글에서 기능이 동작하지 않음
- `imageUrls` 초기화가 첨부 박스 존재에 의존
- 첨부 박스가 없거나 구조가 다를 때 본문 이미지 수집 실패 가능
- 저장 파일명 확장자 포맷 문제
- `001..jpg` 형태로 점(`.`)이 중복될 수 있음
- 일부 글에서 이미지 대신 HTML(403 페이지) 다운로드
- `dcimg*.dcinside.co.kr/viewimage.php` 응답 조건 차이로 본문 이미지가 `html`로 저장되는 케이스 존재
- 본문 이미지 다운로드 시 CSP 경고 노출
- `javascript:` 링크 클릭 트리거 방식 때문에 콘솔 경고 발생
- 시리즈 전체 다운로드 중 일부 글에서 ZIP(첨부) 경로로 분기
- 이후 탭이 닫히지 않아 큐가 멈추는 케이스 존재
- 본문 이미지 외 UI 아이콘(`fix_nik.gif`, `kcap_none.png`)이 섞여 다운로드됨
- 특정 글의 HTML 구조 깨짐 상황에서 `.write_div img` 범위에 비본문 이미지가 포함됨

## 3. 이번 포크에서 반영한 수정/개선

- `manifest.json` 매치 범위 확장
- `board`, `mini`, `mgallery`, `gallery` 모두 대응
- 본문 이미지 수집 로직 강화
- lazy 이미지(`data-original`, `data-src`) 처리 강화
- URL 정규화 및 중복 제거
- `dcinside.co.kr/viewimage.php`를 `image.dcinside.com/viewimage.php`로 정규화
- 확장자 처리 안정화
- 파일명 생성 시 확장자 점 중복 제거
- 확장자 추론을 `HEAD` 우선으로 처리하고 필요 시 fallback
- 시리즈 전체 다운로드 기능 추가
- `[시리즈]` 영역에 `전체 다운로드 (N)` 버튼 추가
- 탭 오픈/처리 큐 안정화
- 동시 다중 오픈 대신 순차 처리 + 지연(기본 2000ms)
- 탭 종료/완료 이벤트 기준으로 다음 요청 처리
- 시리즈 배치 시 본문 다운로드 강제 모드 추가
- 모든 화가 첨부 ZIP이 아닌 본문 이미지 경로로 동작하도록 고정
- 본문 이미지 필터 강화
- `data-fileno` 또는 `viewimage.php` 패턴만 허용하여 UI 아이콘 제외
- 디버그 모드 추가
- 팝업에서 `DebugMode` 토글
- content/background 로그 출력 및 추적 강화

## 4. 설치 방법 (Chrome)

1. 소스코드 다운로드후 압축 풀기
2. 크롬에서 `chrome://extensions` 이동
3. 우측 상단 `개발자 모드` 활성화
4. `압축해제된 확장 프로그램을 로드합니다.` 클릭
5. 압축푼 폴더중 `0.1.1_0` 폴더 선택

## 5. 사용 방법

1. 디시 게시글 페이지 진입
2. 상단 `본문 이미지 다운로드` 버튼 클릭
3. 시리즈 글에서 각 링크 옆 `다운로드` 버튼으로 개별 처리
4. 시리즈 글에서 `[시리즈]` 상단 `전체 다운로드 (N)` 버튼으로 일괄 처리

## 6. 옵션 설명 (팝업)

- `첨부 목록을 상단으로 이동` (`ElementMove`)
- `시리즈 첨부파일 무시` (`IgnoreAttachment`)
- `디버그 로그 활성화` (`DebugMode`)
- `파일명 규칙`
- 지원 키워드: `?title`, `?id`, `?gall`, `?today`, `?wday`

## 7. 디버깅

디버그 모드를 켜면 아래 로그를 확인할 수 있습니다.

- 게시글 탭 콘솔: `[DCID Downloader][CS]`
- 확장 서비스워커 콘솔: `[DCID Downloader][BG]`

확인 포인트 예시:

- 시리즈 배치 큐 등록/탭 오픈/탭 종료
- 다운로드 요청 파일명/확장자 추론 상태
